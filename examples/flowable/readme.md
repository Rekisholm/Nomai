# Flowable-Engine (Java)

Flowable is a lightweight business process engine written in Java. The Flowable process engine can deploy BPMN 2.0 process definitions, create process instances, query them, and access running or historical process instances and related data.

GitHub: 9k+ stars, 2.8k+ forks, and actively maintained.

GitHub link: https://github.com/flowable/flowable-engine

This scene has no CVE. It only verifies java-agent instrumentation availability and SQL rewrite robustness.
